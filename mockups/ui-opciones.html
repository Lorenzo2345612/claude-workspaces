cw · opciones de interfaz

Cada bloque tiene varias opciones con un código (A1, B2…). Dime cuáles eliges, por ejemplo «A2, B1, C3, D2, E1, F2», o mezcla («A2 pero con los atajos de A1»). Todo lo que se ve aquí se puede dibujar en la terminal: solo usa caracteres, colores de texto y de fondo, negrita y subrayado.

A · Barra completa (abajo) — cómo se combinan sesiones, pestañas y atajos

A1Actual · 5 líneas

Atajos arriba, sesiones, y pestañas en recuadros colgando hacia abajo.

  …terminal…
── Alt+m menú · Alt+t pestaña · Alt+n sesión · Alt+←→ sesiones ─────
   fix-matriz ●    review ○    shell     ＋ Claude    ＋ Terminal
─┬──────────────────────┬╮                   ╭──────────────────
 │ bug-185  ~/backend   ││ front  ~/frontend │ ＋          ≡ kyc
 ╰──────────────────────╯╰───────────────────╯

A2Compacta · 3 líneas

Sin línea de atajos: ayuda en ?. Más espacio para la terminal.

  …terminal…
   fix-matriz ●    review ○    shell     ＋ Claude  ＋ Terminal       ? ayuda
─┬──────────────────────┬╮                   ╭──────────────────
 │ bug-185  ~/backend   ││ front  ~/frontend │ ＋          ≡ kyc

A3Mínima · 2 líneas

Pestañas planas (sin recuadro) y sesiones debajo. Muy limpia.

  …terminal…
────────────────────────────────────────────────────────────────────────
 ≡ kyc  bug-185   front   infra  ＋                              ~/work/frontend
    fix-matriz ●   review ○   shell    ＋ Claude  ＋ Terminal

A4Panel lateral

Árbol de pestañas y sesiones a la izquierda; la terminal ocupa el resto. Usa ~28 columnas.

 ≡ kyc                     │
                           │  …terminal…
 ▾ bug-185   ~/backend     │
     fix-matriz ●          │
     review ○              │
 ▾ front     ~/frontend    │
   ▸ arb-copy ○            │
     shell                 │
                           │
 ＋ pestaña  ＋ sesión      │

Ojo: en tmux el panel lateral sería un panel más; se ve bien pero quita ancho a Claude.

B · Pestañas — estilo de cada tarea

B1Recuadros redondeados

La activa en color y abierta hacia la terminal.

─┬──────────────────────┬╮                   ╭─────────
 │ bug-185  ~/backend   ││ front  ~/frontend │ ＋
 ╰──────────────────────╯╰───────────────────╯

B2Bloques de color

Una línea; la activa con fondo azul. Necesita una sola fila.

  bug-185 · ~/backend   front · ~/frontend   infra · ~/ops   ＋

B3Estilo powerline

Flechas entre pestañas. Requiere fuente con glifos powerline (Cascadia la tiene).

  bug-185  front  infra  ＋

B4Subrayado

Texto plano; la activa en negrita con raya debajo.

  bug-185     front     infra     ＋
  ───────     ━━━━━     ─────

C · Sesiones dentro de la pestaña — y su estado

C1Texto con punto de estado (actual)

   fix-matriz ●    review ○    permisos ?    shell     ＋ Claude  ＋ Terminal

C2Píldoras

Fondo gris; la actual con fondo azul.

   fix-matriz ●   review ○   permisos ?   shell    ＋ Claude  ＋ Terminal

C3Estado escrito

Más explícito: dice qué hace cada una.

   fix-matriz  trabajando   review lista   permisos pide permiso   shell

C4Numeradas

Muestra el número para Alt+1..9.

   1 fix-matriz ●   2 review ○   3 permisos ?   4 shell    ＋

D · Avisos — cuando algo pasa en otra pestaña

D1Sin avisos (actual)

Solo ves el estado de la pestaña en la que estás.

 │ bug-185  ~/backend ││ front  ~/frontend │

D2Contadores en la pestaña

● cuántas trabajan · ? cuántas piden permiso.

 │ bug-185 ●2  ~/backend ││ front ?1  ~/frontend │

D3Resaltar la pestaña

La pestaña se pinta cuando una sesión terminó o pide permiso, hasta que entras.

 │ bug-185 ✓ terminó ││ front  ~/frontend ││ infra ? permiso │

D4Mensaje emergente breve

Además de D2 o D3, un aviso de 3 s en la barra.

 ⚑ infra · deploy pide permiso — Alt+↓ para ir
